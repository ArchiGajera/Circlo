# Circlo – Community Sharing Network

Circlo is a web-based community sharing platform that allows users to share items and borrow items from other community members.

## Features

- User Registration and Login
- Share Items
- Browse Available Items
- Send Borrow Requests
- Manage Borrow Requests
- Return Borrowed Items
- Rate and Review Items

## Tech Stack

- Frontend: HTML, CSS, Vue.js
- Backend: Node.js, Express.js
- Database: MySQL
- Database Management: phpMyAdmin
